Access and pricing

Clear status. No checkout surprises.

ZervxHub is still a development project. This page describes what the repository implements today; it is not an offer to sell access.

No paid plans or payment processing are available.

There is no checkout, subscription, purchase flow, refund workflow, or payment provider connected to this project. Do not send payment for ZervxHub access.

In development

Free license keys

The code supports administrator-configured, 24-hour keys for approved games.

  • One active issuance per member during a 24-hour cooldown
  • Validation is scoped to an approved Roblox universe
  • Keys can be revoked by an authorized developer or guild moderator

A working deployment, approved game, and connected Discord server are required. No hosted availability is promised.

Administrator provisioned

Developer access

There is no public signup form or self-service developer dashboard.

  • Developer credentials are created by an administrator
  • Each registered game requires review before key validation
  • API credentials are shown once and must be kept private

See the onboarding guide for the current manual process and its setup requirements.

Not available

Paid subscriptions

Recurring billing and paid entitlements have not been implemented.

  • No plans, prices, or renewal terms are defined
  • No payment provider or webhook integration exists
  • No billing, refund, tax, or customer portal is available

Any future commercial launch needs legal, privacy, support, and payment-provider review first.
