Help and troubleshooting

Find the cause. Keep credentials private.

Use these checks for a self-hosted development setup. There is no staffed support desk or service-level commitment at this time.

Key rejected or expired

  1. Confirm the key was issued for this member and is still within its 24-hour validity period.
  2. Check that the Roblox Universe ID is registered, approved, and allowed for the key.
  3. Confirm the developer is active and the key has not been revoked.
  4. Check the Worker's logs privately for database or configuration errors.

Discord bot cannot issue keys

  1. Verify the guild ID and active guild-to-developer integration.
  2. Confirm the selected game is approved for that developer.
  3. Check that the bot and Worker use the same dedicated bot API token.
  4. Check bot hosting logs for startup errors without printing environment values.

Roblox cannot reach the API

  1. Enable HTTP requests in the experience's Studio security settings.
  2. Verify the server script's Worker URL and the Worker's configured Universe IDs.
  3. Keep the request in a server Script; never move the API call or credentials into the LocalScript.
  4. Test in a private experience you control before enabling players.

Configuration or database issue

  1. Check that required Worker secrets are configured and non-empty.
  2. Review pending migrations and apply them to the intended database only after review.
  3. Confirm the Discord bot's URL uses HTTPS outside local development.
  4. Do not paste tokens, raw keys, or database credentials into public issue reports.
Support is currently community-based.

Use the project repository to report a reproducible issue. GitHub issue reports may be public: include versions, sanitized logs, and steps to reproduce, but remove all secrets and personal data. Do not submit payment; no paid service exists.
